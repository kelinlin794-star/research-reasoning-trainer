# 科研问题推理训练器

> 不帮你「总结」论文，而是把论文从「最终成品」还原成「问题解决的过程」，训练你像研究者一样思考。

一个基于 Streamlit 的交互式训练工具，用「现实问题 → 历史瓶颈 → 作者设计 → 去魅」的闭环，带你走完一篇论文背后的完整推理链。

## 它不是什么

它**不是**论文总结器。总结器把论文当成最终成品告诉你结论；这套训练器把论文还原成过程，逼你先动脑，再看答案。

## 核心原则

1. **不神化创作者**：把创新还原成「面对约束 → 测量系统 → 发现瓶颈 → 提出方案」的工程决策，而非「天才灵光」。
2. **不做术语→定义**：坚持「问题 → 需求 → 概念 → 方法」的逻辑链条。
3. **严格证据分层**：每条内容都标注来源层级，绝不假装读心作者的真实想法。

## 页面结构

| 页面 | 功能 |
|---|---|
| 首页 | 选择论文、查看训练入口 |
| 推理训练 | 7 步闭环向导（核心），含防剧透门控 |
| 历史演进 | 领域问题线 / 技术演进线 |
| 去魅档案 | 我的猜想、局限回顾与去魅心得笔记 |
| 方法论 | 训练理念与证据分层图例 |

## 训练闭环（7 步）

先猜（给脚手架）→ 看作者方案 → 拆解方法 → 看实验验证 → 找局限 → 去魅 → 回归历史演进。

核心是「先猜再看答案」——你的猜想对不对不重要，重要的是你完成了一次研究者式的思考。

## 本地运行

```bash
pip install -r requirements.txt
streamlit run app.py
```

## 目录结构

```
research-trainer/
├── app.py                  # 首页（选论文）
├── common.py               # 共享模块：数据加载、证据徽标、会话状态
├── pages/
│   ├── 1_推理训练.py        # 7 步闭环向导（核心）
│   ├── 2_历史演进.py        # 两条外部时间线
│   ├── 3_去魅档案.py        # 学习记录
│   └── 4_方法论.py          # 理念说明
├── data/
│   └── realtime_vla.json   # 论文训练数据（含证据分层标注）
└── test_app.py             # AppTest 自动化验证
```

## 如何添加一篇新论文

在 `data/` 下新增一个 JSON 文件，按 `realtime_vla.json` 的结构填写即可，无需改动任何代码。字段说明见 `common.py` 顶部注释。

## 示例论文

**Running VLAs at Real-time Speed**（arXiv:2510.26742）—— 让十亿参数的视觉-语言-动作（VLA）模型在单张消费级 GPU 上以实时速度运行。
